# Assist as Momentum + Push Yourself as Limiter

## Observation 1: Unify Assist with Create an Opening

### Current System

**Create an Opening (self):**
- Spend 1 Momentum
- Gain +1 Boon + 1 Edge
- Before your next Action Roll

**Assist (ally):**
- Mark 1 Stress
- Grant ally +1 Boon
- Before their Action Roll

**These serve similar purposes but use different resources and grant different benefits.**

---

### Proposed: Unified Momentum System

**Create an Opening:**
- Spend 1 Momentum before a roll
- If for yourself: +1 Boon + 1 Edge
- If for an ally: +1 Boon + 1 Edge (they get the benefit)

**This unifies all "spend resource to improve a roll" under Momentum.**

---

### What This Achieves

**Stress becomes purely reactive:**
- Marks from Consequences (defensive buffer)
- Marks from activating Talents (special abilities cost)
- Never voluntarily spent for general benefits

**Momentum becomes the proactive resource:**
- Spend to improve ANY roll (yours or ally's)
- Spend to reduce Consequences (Resist)
- THE resource for tactical decisions

**Cleaner design:** One resource for proactive improvements.

---

### Implications

#### Teamwork Changes

**Current Assist:**
- Multiple allies can Assist (each marks Stress)
- Can be spammed (if allies have Stress to spare)
- Each ally makes individual decision (mark my Stress?)

**New "Create an Opening for Ally":**
- One person spends Momentum to help another
- More precious (Momentum is limited)
- Strategic choice (who should I help? when?)

**Example:**
> "I'm spending 1 Momentum to Create an Opening for you. I shout tactics and create a distraction, giving you +1 Boon and 1 Edge on your attack."

**This feels more tactical** - coordinating resources as a team rather than everyone spending Stress individually.

---

#### Momentum Economy Impact

**If Momentum can be spent on allies, it needs to support:**
1. Create an Opening (self) - +1 Boon + 1 Edge
2. Create an Opening (ally) - +1 Boon + 1 Edge
3. Resist Consequence - reduce severity

**That's 3 uses competing for limited Momentum.**

**Current Momentum sources:**
- Triumphs (2+ sixes) - rare
- Build Momentum (Special Effect) - costs progress
- Optional GM grants

**You'd need to increase sources/capacity:**
- Increase max (3 → 4-5)
- More Talent sources
- Start with 1-2 Momentum
- More GM grants for teamwork/clever plans

---

#### Multiple Allies Helping

**Current:** 3 allies can all Assist one person (each marks Stress)

**New:** Only one person can Create an Opening for that roll? Or multiple?

**Options:**

**A. Only one Create an Opening per roll**
- Prevents stacking
- Makes it more strategic (who helps?)
- Simpler

**B. Multiple people can Create an Opening**
- Each spends 1 Momentum
- Each grants +1 Boon (subject to ±2 cap)
- Only one grants Edge (or first one?)
- More flexible but complex

**Recommendation: Option A** (only one Create an Opening per roll, whether for self or ally).

**Subject to ±2 Boon cap anyway**, so multiple wouldn't stack much.

---

### Rules Text

**Create an Opening (revised):**
> Before any Action Roll, you may spend 1 Momentum to Create an Opening. The character making the roll gains **+1 Boon and +1 Edge**.
> 
> Describe how you create the advantage - tactical positioning, shouted advice, a distraction, revealing a weakness.
> 
> Only one Create an Opening can be used per Action Roll.

**Assist:** ~~Removed~~ (merged into Create an Opening)

## Observation 2: Push Yourself as Rate Limiter

### The Problem Without "Push Yourself" Framework

**If Talents just say "mark 1 Stress to [effect]":**

**Example Talents:**
- Surge: Mark 1 Stress to gain +1 Boon and mark 2 progress
- Iron Will: Mark 1 Stress to gain +1 Boon and resist mental effects
- Quick Strike: Mark 1 Stress to gain +1 Boon and act first

**Can you activate ALL of them on one roll?**

If yes:
- Mark 3 Stress total
- Gain +3 Boons (capped at +2) + all special effects
- Broken / too powerful

If no:
- How do you enforce the limit?
- Just write "once per action" on each Talent? (redundant)

---

### Solution: Push Yourself as Rate Limiter

**Push Yourself** = framework that limits to once per action

**Talents say:**
> "When you Push Yourself [in this context], [effect]"

**Rules:**
> You can only Push Yourself once per Action Roll. Some Talents grant special effects when you Push Yourself in specific contexts. You may only activate one such Talent per Push.

**Example Talents (rewritten):**
- **Surge:** When you Push Yourself during a Clash, gain +1 Boon and mark 2 progress instead of 1.
- **Iron Will:** When you Push Yourself to resist a mental effect, gain +1 Boon and advantage on the roll.
- **Quick Strike:** When you Push Yourself to attack before an enemy, gain +1 Boon and act first.

**The character Pushes once, activates one Talent.**

---

### How This Works

**Step 1:** Player decides to Push Yourself (mark 1 Stress)

**Step 2:** Player chooses which Talent to activate (if multiple apply)

**Step 3:** Gain Talent's benefit

**Can't stack multiple Talents** because you can only Push once per action.

---

### But What's the Baseline Benefit?

**If Push Yourself is just a Talent framework (no baseline benefit):**

**What if you Push Yourself but no Talent applies?**

**Options:**

**A. No baseline benefit**
- Push Yourself ONLY does something if a Talent activates
- If no Talent applies, you can't Push
- Clearest limiter

**B. Baseline: +1 Boon**
- Push Yourself always grants +1 Boon (baseline)
- Talents add to this (when they apply)
- But this brings back the baseline mechanic we were removing...

**C. Baseline: Convert Setback (post-roll)**
- Push Yourself is only used post-roll (if you failed)
- Mark 1 Stress to convert Setback → Conflict
- Talents trigger when you do this
- But this makes it post-roll, not pre-roll (affects Talent timing)

---

### My Recommendation: Option A (No Baseline)

**Push Yourself is ONLY for Talents.**

**You can only Push if you have a Talent that applies to this situation.**

**This creates interesting Talent choices:**
- Early game: Few Talents, so you rarely Push
- Late game: Many Talents, so you Push often (in various contexts)

**Talents become your main way to "spend Stress for power."**

---

### Alternative: Keep Minimal Baseline

**If you want Push Yourself to be available to everyone:**

**Baseline Push Yourself (minimal):**
> When you make an Action Roll, you may mark 1 Stress to Push Yourself. Gain +1 Boon. If you have a Talent that triggers when you Push Yourself in this context, you may activate it (gaining its benefit in addition to the +1 Boon).

**This keeps:**
- Universal option (everyone can Push for +1 Boon)
- Rate limit (only once per action)
- Talent framework (Talents add to the Push)

**But it brings back the baseline mechanic we were trying to remove.**

---

## Combined Proposal: Full Streamlined System

### Remove

1. **Push Yourself (baseline "+1 Boon")** - becomes Talent-only framework
2. **Assist** - merged into Create an Opening
3. **Expertise** - removed

### Keep/Modify

1. **Push Yourself (framework)** - rate limiter for Talents (once per action)
2. **Create an Opening** - unified Momentum spend (self or ally)
3. **Momentum** - becomes THE proactive resource

---

### New Resolution (7 Steps!)

1. **Frame** (Vantage, Stakes)
2. **Pool** (Approach + Trait)
3. **Boons/Banes** (circumstantial, ±2 cap)
4. ~~Push Yourself removed (now Talent-only)~~
5. **Roll**
6. **Raw Outcome**
7. **Edge** (cancel Complications)
8. **Complications** (apply)
9. ~~Expertise removed~~
10. **Final Outcome**

**Effective: 7 steps** (Steps 4 and 9 eliminated)

**Decision points:**
- Before roll: Create an Opening? (Momentum, for self or ally)
- During roll: If you have Talents, you could Push Yourself (mark Stress, activate one Talent)
- After roll: Resist Consequence? (Momentum)

**Cleaner than current 10 steps.**

---

### Resources Summary

**Momentum (Proactive/Tactical):**
- Create an Opening (+1 Boon + 1 Edge, self or ally)
- Resist Consequence (reduce severity)
- Gain from: Triumphs, Build Momentum, GM grants
- Max 3-5 (may need to increase)

**Stress (Reactive/Defensive):**
- Marks from: Consequences (automatic)
- Marks from: Push Yourself (activate Talents)
- Clears via: Short Rest, Long Rest

**Clean separation:** Momentum = choose when to spend (tactical). Stress = marks when you're hit or push limits (pressure).

---

## Concerns & Solutions

### Concern 1: Momentum Scarcity

**Problem:** If Momentum is the only way to boost rolls proactively, and sources are limited, players feel resource-starved.

**Solutions:**
1. **Increase capacity** (max 3 → 5)
2. **More sources:**
   - Start each session with 2 Momentum
   - Talents grant Momentum (on certain triggers)
   - GM grants for clever plans, good roleplay
3. **Accept scarcity** (Momentum is precious, use wisely)

**Recommendation:** Increase capacity to 5, add more Talent sources.

---

### Concern 2: Characters Without Talents Feel Weak

**Problem:** If Push Yourself is Talent-only, characters without relevant Talents can't mark Stress for benefits.

**Solutions:**
1. **Everyone gets Talents** (make sure all characters have at least 2-3 Talents by level 1)
2. **Accept power curve** (early game = fewer options, late game = many options)
3. **Keep baseline Push** (mark Stress for +1 Boon, universal)

**Recommendation:** Ensure all characters have at least 2-3 Talents at creation, covering different situations (combat, social, exploration).

---

### Concern 3: Teamwork Becomes More Expensive

**Problem:** Current Assist is "cheap" (mark 1 Stress). New system requires precious Momentum.

**Solutions:**
1. **Accept higher cost** (teamwork is strategic, not spammable)
2. **Increase Momentum availability** (so spending on allies is viable)
3. **Keep Assist separate** (Stress-based, unchanged)

**Recommendation:** Accept higher cost. Teamwork becomes more strategic ("I'll use my Momentum to set you up for the killing blow").

---

## Final Recommendation

### Implement Both Changes

1. **Remove baseline Push Yourself, keep as Talent framework**
   - Talents say "When you Push Yourself [context], [effect]"
   - Only one Push per action (rate limit)
   - No baseline benefit unless Talent applies

2. **Merge Assist into Create an Opening**
   - Spend 1 Momentum before any roll (self or ally)
   - Grant +1 Boon + 1 Edge
   - Only one per roll

3. **Remove Expertise**

**Result:**
- 10 → 7 effective steps
- Momentum = THE proactive resource
- Stress = defensive buffer + Talent fuel
- Cleaner, more streamlined

**But you MUST adjust Momentum economy:**
- Increase capacity (3 → 5)
- Add sources (Talents, session start, GM grants)
- Make Triumphs slightly more common? (or add sources)

---

## Alternative: Keep Assist Separate (Conservative)

**If merging Assist feels too radical:**

**Keep:**
- **Assist** (mark 1 Stress for ally's +1 Boon) - unchanged
- **Create an Opening** (spend 1 Momentum for self: +1 Boon + 1 Edge)

**Remove:**
- **Push Yourself (baseline)** - becomes Talent framework only
- **Expertise**

**Result:**
- 10 → 8 steps (Push + Expertise removed)
- Assist remains Stress-based (cheap teamwork)
- Create an Opening remains Momentum-based (powerful self-boost)
- Cleaner separation: Stress for allies, Momentum for self

**This is lower risk** (less change to teamwork mechanics).

---

## My Strongest Recommendation

**Conservative Path (Lower Risk):**

1. Remove baseline Push Yourself (Talent framework only)
2. Keep Assist as-is (Stress for ally's Boon)
3. Remove Expertise
4. Result: 8 steps

**Then playtest.** If Assist still feels redundant with Create an Opening, merge them later.

**Radical Path (Higher Reward):**

1. Remove baseline Push Yourself (Talent framework only)
2. Merge Assist into Create an Opening (Momentum for self or ally)
3. Remove Expertise
4. Increase Momentum economy (capacity + sources)
5. Result: 7 steps

**Both are good.** Conservative is safer. Radical is cleaner but requires Momentum economy tuning.

## Rules Text Examples

### Push Yourself (Framework)

> **Push Yourself**
> 
> When you make an Action Roll, you may mark 1 Stress to Push Yourself. You can only Push Yourself once per Action Roll.
> 
> Some Talents grant special effects when you Push Yourself in specific contexts. If you have such a Talent and the context applies, you gain that Talent's benefit when you Push.
> 
> If no Talent applies, you cannot Push Yourself.

**Note:** This version has no baseline benefit. Push is only useful if you have Talents.

---

### Create an Opening (Unified)

> **Create an Opening**
> 
> Before any Action Roll, you may spend 1 Momentum to Create an Opening. The character making the roll gains **+1 Boon and +1 Edge**.
> 
> Only one character can Create an Opening for a given roll.

---

### Create an Opening (Conservative - Self Only)

> **Create an Opening**
> 
> Before you make an Action Roll, you may spend 1 Momentum to Create an Opening for yourself. You gain **+1 Boon and +1 Edge**.

**Assist (Unchanged):**
> When an ally makes an Action Roll, you may mark 1 Stress to grant them **+1 Boon**.
