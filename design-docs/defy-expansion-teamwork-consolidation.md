## Design Rationale

### Problem: Defy Was Underexplained

The original Defy section listed intent effects but didn't explain:
- What each effect does mechanically
- How long effects last
- When to use each one
- How Create Advantage differs from Assist

This left players uncertain about what Defy could actually accomplish.

### Solution: Detailed Intent Framework

Each intent effect now has:
1. **What it does** (mechanical clarity)
2. **Examples** (concrete applications)
3. **Duration** (when relevant)
4. **Comparison to alternatives** (when relevant)

## The Full Support Toolkit

Players now have four ways to help allies:

### 1. Assist (Momentum) — Direct Boost
- **Cost:** 1 Momentum + shared risk + fictional positioning
- **Effect:** Ally gains +1 Boon +1 Edge on specific action
- **When to use:** Critical action, you're in position to help directly
- **Chapter 5**

### 2. Create Advantage (Action) — Setup
- **Cost:** Your action
- **Effect:** Grant +1 Boon, inflict Condition, or create environmental advantage
- **When to use:** Multiple allies benefit, or lasting effect desired
- **Chapter 2 (Defy)**

### 3. Build Momentum (Trait) — Resource Generation
- **Cost:** None (Trait invocation on Conflict+)
- **Effect:** Grant ally 1 Momentum (they self-buff)
- **When to use:** Safe support, indirect setup
- **Chapter 6**

### 4. Push Yourself (Talent) — Domain-Specific
- **Cost:** 1 Stress (or Talent checkbox)
- **Effect:** Varies by Talent
- **When to use:** Talent-specific scenarios
- **Chapter 4 + Chapter 9**

## Gameplay Implications

### Create Advantage vs. Assist

**Create Advantage (Defy):**
- Uses your action (you don't attack/progress directly)
- Can affect multiple allies or enemies
- Can create lasting environmental changes
- Only grants +1 Boon (no Edge)
- No shared risk

**Assist (Momentum):**
- Uses Momentum (not your action - you can still act)
- Only affects one ally's one action
- Grants +1 Boon AND +1 Edge
- Requires positioning + shared risk
- More powerful but more constrained

### Support Character Playstyles

**"Tactician" (Defy-focused):**
- Uses actions to set up allies
- Creates advantages, debuffs enemies, controls battlefield
- Doesn't need Momentum economy
- Best when multiple allies benefit

**"Coordinator" (Momentum-focused):**
- Builds Momentum via Traits
- Feeds Momentum to allies via Build Momentum
- Assists critical actions
- Needs good Trait coverage + Momentum generation

**"Hybrid"**
- Mixes both approaches based on situation
- Defy when multiple allies benefit
- Assist when one ally needs critical boost

## Examples

### Tactical Support Chain

**Round 1:**
- **Scout** uses Defy to Create Advantage: "I throw sand in the knight's eyes!"
- Success → Knight gains **Blinded 1** (1 Bane on sight-based actions)
- **Fighter** attacks blinded knight with advantage

**Round 2:**
- **Scout** uses Sense to find weakness (Conflict)
- Invokes Trait → Build Momentum (grants Fighter 1 Momentum)
- **Fighter** spends Momentum to Create an Opening (self) → attacks with +1 Boon +1 Edge

**Round 3:**
- **Mage** gets in position next to Fighter
- **Mage** Assists Fighter's killing blow (spends 1 Momentum, shares risk)
- **Fighter** attacks with +1 Boon +1 Edge from Assist

All three support methods used across three rounds, each optimal for the situation.

## Design Notes

### Why Expand Defy?

Defy is the most versatile Action but was the least explained. Players need to understand:
- It's not just "dodge and climb"
- It's the tactical action (reposition, setup, control)
- It's a support tool, not just personal defense

### Why Consolidate Teamwork in Chapter 5?

Chapter 5 (Momentum) is already about:
- How to support allies (Create an Opening/Assist)
- Resource economy
- Team coordination

Moving all teamwork discussion there creates a **one-stop reference** for "how do we work together?"

### Why Keep Create Advantage Separate from Assist?

They serve different purposes:
- **Create Advantage:** Action-based, affects situation broadly
- **Assist:** Momentum-based, pinpoint boost to one action

Both are valuable in different scenarios. The comparison helps players choose.
